## 🏗 프로젝트 구조 및 기술 스택 파악

**LandingUp**은 단순한 챗봇이 아닌, **다중 AI 파이프라인(Multi-Agent Pipeline)**과 이를 시각적으로 검증할 수 있는 **Interactive 3D 프론트엔드 환경**이 결합된 풀스택 웹 애플리케이션입니다.

### 💻 사용된 주요 기술 스택
- **Backend (API & AI Pipeline)**
  - `Python 3.x`, `FastAPI` (REST API 서빙)
  - `PyMuPDF (fitz)` (PDF 브랜드 매뉴얼 구문 분석)
  - `Shapely`, `NetworkX` (환각 없는 기하학적 충돌 예측 및 최단거리 관람 동선 연산)
  - `Anthropic / OpenAI API` (Agent LLM 판단 로직)
- **Frontend (3D Dashboard)**
  - `React.js` + `Vite` (SPA 뷰단)
  - `TypeScript` (타입 안정화 및 데이터 스키마 통신)
  - `Tailwind CSS` (스타일링/유틸리티 CSS)
  - `Three.js` + `@react-three/fiber` + `@react-three/drei` (웹브라우저 내 WebGL 2D/3D 하드웨어 렌더링)
- **Architecture**
  - **Zero-Hallucination 패턴**: LLM(Agent)은 '설계 방향성'만 지시하고, 실제 공간/충돌 계산은 파이썬 코드가 강제로 수학 연산하도록 분리.

## ✅ 현재까지 완벽히 구현된 내용 (Implemented)

### 1. 강력한 AI 백엔드 파이프라인 연동 (`api/server.py` & `ai/`)
- **[Agent 1 & 2]** 사용자로부터 전달받은 브랜드 매뉴얼 파일(PDF 등 인코딩 폴백 처리 완비)과 도면 이미지를 읽어들여 요구사항 폭, 설비 위치(`facilities`), 가용 면적(`usable_ranges`)을 수학적 좌표로 변환.
- **[Agent 3]** 설정된 가용 면적(파란 공간) 내부에 조형물(Box)을 배치하고, 스프링클러 반경(빨간색 출입 금지)을 침범하지 않게 테트리스식 연산.

### 2. 고도화된 3D/2D 혼합 시각화 대시보드 (`App.tsx` & `FloorPlanVisualizer.tsx`)
- **자동 2D/3D 전환 및 리셋 컨트롤러**: 
  - 기본적으로 직교 카메라(Orthographic)를 사용해 오차 없는 2D 평면 CAD 도면 모드로 로딩.
  - [3D 뷰] 토글 시 원근 카메라(Perspective)로 즉시 전환되어 입체 조형물을 감상 가능.
- **다이내믹 뷰 조작계 스위칭**:
  - `2D 모드`: 왼쪽 마우스 드래그 시 화면이 돌아가지 않고 **지도처럼 부드럽게 화면 이동(Pan)**.
  - `3D 모드`: 왼쪽 마우스 드래그 시 입체를 **자유자재로 돌려보는 회전(Orbit)** 기능 활성화.
- **스마트 UI 텍스트 오버레이 (Billboard & Scaling)**:
  - 2D 탑뷰 모드에서도 글씨가 종잇장처럼 사라지지 않게 글씨 각도를 90도 눕히는 기능.
  - 폰트 크기가 조형물(박스) 가로 폭에 비례해 자동 축소(`Math.min`)되며, 벗어날 경우 자동 줄바꿈(`maxWidth`).

### 3. 직관적인 양방향 인터랙션 (Interactive Highlight)
- 패널의 텍스트 리포트 클릭 시, 백엔드로부터 받은 고유 객체 ID를 기반으로 캔버스 내 조형물 및 시설물(`activeHighlightId`)이 핫핑크/네온형광 노란색으로 빛(Emissive)을 뿜어 직관적 식별 가능.

## 🚧 아직 구현되지 않은 기능 (To-Do / Unimplemented)

### 1. 휴먼 마스킹 모드 (Human-in-the-loop 수동 개입)
- **개념**: AI가 놓치거나, 도면 이미지가 흐려 인식하지 못한 소화전(Dead Zone)이나 출입구를 인간 작업자가 직접 **캔버스를 우클릭/타겟팅해서 강제 지정**하는 기능.
- **잔여 과제**: 캔버스 내 Raycaster를 통해 획득한 클릭 좌표 데이터를 다시 FastAPI 백엔드로 쏴서, 그 주위 공간(가용 구역)을 깎아내고 "재배치 연산"을 돌리는 통신 체계 구현.

### 2. 다각도 벽체(Wall) 배치 에디터 
- **개념**: 2D 뷰에서 점과 점 사이를 여러 번 마우스로 클릭해 직접 "커스텀 벽체"가 쳐지도록 폴리곤(Polygon)을 긋는 툴 기능 미구현.

### 3. Agent 4 (최종 검토 및 수출 리포트 작성)
- **개념**: Agent 1~3이 만든 `FinalLayoutData` 결과를 가지고 안전 점수, 통과율, 견적서 개요 등을 텍스트화하여 요약 정리해 주는 문서 AI 출력 기능.
- **잔여 과제**: 프론트엔드 UI 하단 혹은 팝업창을 통한 최종 검수 리포트 컴포넌트 개발.
