## 2. 조형물 (피규어 / 스탠딩 / 포토존) 배치 규정

### 2-1. 헬로키티 메인 조형물 — 여백 규정

헬로키티 메인 조형물(피규어·스탠딩·대형 조형물)의 **사방 최소 이격 거리는 1,500mm** 이상을 확보하여야 합니다.

조형물 주변에 다른 집기, 선반, 진열대, 포토존 구조물이 침범하면 안 됩니다.  
단, 브랜드 공식 포토존 배경 패널은 조형물 후방(입구 반대 방향) 배치 시 **800mm 이상** 이격으로 완화 적용합니다.

> **요약**: 헬로키티 조형물 사방 1,500mm 띄움. 후방 배경 패널만 800mm로 완화.

### 2-2. 서브 캐릭터 조형물 — 여백 규정

마이멜로디, 시나모롤, 폼폼푸린 등 서브 캐릭터 조형물은 **사방 최소 800mm** 이격을 유지합니다.

### 2-3. 캐릭터 조형물 정면 방향 규정

모든 캐릭터 조형물은 **입구(방문객 진입 방향) 정면**을 향하도록 배치합니다.  
꺾임 허용 범위: 입구 정면 기준 ±15도 이내.

벽면 부착형 포토존 패널은 예외이며, 방문객 동선에서 자연스럽게 시선이 닿는 방향으로 설치합니다.

> **요약**: 조형물 정면은 반드시 입구를 향할 것. ±15도 허용.

### 2-4. 쿠로미 — 헬로키티 관계 규정

쿠로미(Kuromi) 조형물은 헬로키티 조형물과 **동일 시야 내 근접 배치를 금지**합니다.  
두 캐릭터는 **서로 다른 존(Zone)에 분리** 배치하거나, 불가피한 경우 최소 **3,000mm 이상** 거리를 유지합니다.

마이멜로디 — 쿠로미는 동일 존 배치 가능(공식 파트너 관계).

> **요약**: 쿠로미와 헬로키티는 분리 배치할 것. 같은 공간이면 3,000mm 이상 이격.

### 2-5. 마이멜로디 — 헬로키티 관계 규정

마이멜로디와 헬로키티는 **같은 존 배치 허용**. 단, 각 조형물 여백 규정(1,500mm / 800mm)은 각각 독립적으로 적용합니다.

## 3. 로고 사용 규정

### 3-1. 로고 여백 (Clear Space)

헬로키티 공식 로고(텍스트 로고 / 페이스 로고) 사용 시, 로고 장변 길이의 **1/4에 해당하는 여백**을 사방에 확보합니다.

인쇄·출력물 기준:
- A4 (210mm) 적용 시: 로고 장변 약 80mm → 사방 여백 최소 **20mm**
- 대형 현수막(2,000mm 이상) 적용 시: 사방 여백 최소 **500mm**

공간 설치물(사이니지·패널)에서 로고 사방 최소 이격: **500mm**

> **요약**: 공간 설치 사이니지 기준 로고 사방 500mm 여백 확보.

### 3-2. 로고 금지 사항

- 로고 위에 다른 캐릭터 겹침 배치 금지
- 로고 색상 임의 변경 금지 (공식 컬러 외 사용 불가)
- 로고 변형·왜곡·회전 금지

### 4-1. 조형물 / 구조물 소재 금지

아래 소재는 헬로키티 공간 연출에 사용을 금지합니다:

| 금지 소재 | 사유 |
|---|---|
| **금속(Metal) — 미가공 철재, 알루미늄 노출면 포함** | 브랜드 이미지(따뜻함/부드러움)와 상충 |
| **투명 아크릴 (무채색 계열)** | 브랜드 컬러 표현 불가, 저가 이미지 |

| **PVC 소재 (경질 회색/검정)** | 브랜드 컬러 저해 |

### 4-2. 바닥재 규정

바닥재는 **미끄럼 방지 처리 필수**. 광택 비닐계 바닥재 단독 사용 금지.

## 5. 포토존 규정

### 5-1. 포토존 위치

포토존은 방문객 동선의 **중간~후반부**에 배치를 권장합니다.  
입구 직전 배치는 동선 정체를 유발하므로 금지합니다.

### 5-2. 포토존 최소 면적

포토존 전면 개방 공간(방문객 대기·촬영 공간): **최소 1,500mm × 1,500mm** 확보.

## 6. 공간 구성 권장 레이아웃

### 6-1. 권장 존 구성

| 존 이름 | 위치 | 주요 집기 |
|---|---|---|
| Welcome Zone | 입구 | 헬로키티 메인 조형물, 환영 사이니지 |
| Display Zone | 중앙~벽면 | 진열 선반, 굿즈 디스플레이 |
| Photo Zone | 중간~후반부 | 포토 배경 패널, 소품 |
| Purchase Zone | 출구 방향 | 계산대, 포장 카운터 |

### 6-2. 헬로키티 메인 조형물 — 필수 배치 위치

헬로키티 메인 조형물은 **입구에서 진입 시 정면 또는 좌우 45° 이내 시야**에 들어오는 위치에 반드시 배치합니다.

입구를 등지거나 후방 코너에만 배치하는 것은 허용되지 않습니다.
